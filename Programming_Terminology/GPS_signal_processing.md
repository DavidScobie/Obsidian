**GPS signal structure**
GPS uses [[CDMA]] and [[PSK]] for signal modulation. Therefore we have: [[carrier_wave]], [[Pseudo-Random_Noise]] code, and data (navigation message). pseudorandom code and data are modulated through PSK onto carrier wave, which is in the form of a sine wave. Then satellites will transmit the GPS signal out into space.

**GPS data demodulation**
This is achieved by performing correlation of received signal and a copy of local signal generated by the user. The copied signal is composed of [[carrier_wave]] and [[Pseudo-Random_Noise]] code, without [[Navigation_message]] (the user doesn’t know anyway).
In order to have a correlation peak, receive and copied signals should have the same:
- Carrier wave frequency,
- Carrier wave phase,
- PRN code sequence
- PRN code phase.
This is achieved through Signal Acquisition and Signal Tracking.
Different satellite distances lead to different phases for carrier wave and PRN. Different speeds (from doppler shift) result in shifts of the carrier frequency.

**Signal Acquisition**
- The user knows the PRN code sequence for each satellite but doesn’t know which satellites are visible. If the received signal doesn’t have the transmitted signal of a certain satellite, then it indicates the satellite is not visible. The process to determine visible satellites is called signal acquisition.
- Signal acquisition can be implemented by detecting the correlation peak of the received signal and copied signal. Before acquisition, carrier wave frequency and code phase are unknown, so the user will traverse different combinations of Doppler shifts and code phases to generate a copied signal to correlate with the received signal.
![[signal_acquisition_diagram.png]]
Therefore this is a 3D search over:
- satellite dimension (approx. 30 satellites)
- Doppler dimension (equal to 41, if bin size = 500 𝐻𝑧 within ± 10 𝑘𝐻𝑧 range)
- Code phase dimension (equal to PRN code length if bin size = 1 chip)
The total search space is 31 × 41 × 1023 (HUGE!) for C/A signal acquisition. For P code signal, it’s even worse given that the P code phase dimension is 6.18 × 10¹²!! Therefore we need speed-up priors.

**Speed up priors**
Given the users rough location, it already knows which satellites are visible.
We can also estimate the doppler shift and code phase of the satellites

**Signal Tracking**
The grid above involves searching over 500Hz or 1 chip (still quite large). Signal tracking fine tunes this.
We use [[Frequency-locked_loop]], [[Phase-locked_loop]], [[Delay_locked_loop]]s for this.
These involve negative feedback loops (output is used to decrease input). Similar to controlling temperature of a bath with minor hot and cold water adjustments based on feeling hot or cold.

**Demodulation after tracking**
[[Phase-locked_loop]] and [[Delay_locked_loop]] make sure the copied signal has the maximum correlation with the received signal. Data demodulation is then indicated by correlation result.
