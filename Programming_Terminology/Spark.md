#framework 
Spark is an open source framework focused on interactive query, machine learning, and real-time workloads. It does not have its own storage system, but runs analytics on other storage systems like HDFS.

Hadoop is a project within the [[Apache]] foundation.

https://www.youtube.com/watch?v=IELMSD2kdmk
Written in [[Java]] and runs on the [[JVM]].
Most calculations are done on memory rather than disk, so it is super-fast, hence 80% of the fortune 500 companies use Spark.
Spark's API's can be used with wrappers for [[python]], [[SQL]], [[C_sharp]], and more...
It can also be used with [[big_data]] like [[kubernetes]] the work can be scaled across unlimited machines.
Spark's [[machine_learning]] library (MLlib) is widely used.
